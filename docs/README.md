## Recommended rollout order

1. **Day 0 — Soft-test on your own** — sign in as admin, create one test team, add yourself and one trusted colleague as members. Walk through requesting → approving → downloading a signed doc.
2. **Day 1 — Distribute the onboarding form** to department heads. Use the template in `onboarding-form.csv`.
3. **Day 3–5 — Collect responses**, then bulk-import each team via **Admin → Onboard team**.
4. **Day 5 — Send the launch announcement** (in `launch-announcement.md`) to all users with their credentials.
5. **Day 6 onwards — Live**.
