# Moving Several Documents at Once — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a person tick several finished documents and move them into a folder (or out of one) in one go.

**Architecture:** One new all-or-nothing server call (`PUT /api/folders/items`, transaction, every id authorised before any write). On the client, `FolderedList` owns selection state and renders a Select button and a selection bar; `RequestRow` swaps its drag grip for a checkbox when selectable; `MoveToMenu` is reused on the bar. Spec: `docs/superpowers/specs/2026-09-24-bulk-move-design.md`.

**Tech Stack:** Express + mysql2 (transactions via `getPool().getConnection()`), React 18, lucide-react, existing `useFolders` hook, `server/test/folders.integration.mjs`, Playwright in the session scratchpad.

- [ ] **Step 3: Implement** — in `folders.js`, import `getPool` from `../db.js`, add before the `/items/:requestId` route:

```js
// PUT /api/folders/items { requestIds: [...], folderId | null } — several at once.
// Every id is checked BEFORE anything is written, and the writes share one
// transaction, so a selection either moves whole or not at all. Declared
// before /items/:requestId so "items" is never read as a request id.
const MAX_BULK = 200;
router.put("/items", authRequired, async (req, res, next) => {
  try {
    const raw = req.body?.requestIds;
    if (!Array.isArray(raw) || raw.length === 0) return res.status(400).json({ error: "Choose at least one document" });
    const ids = [...new Set(raw.map((v) => String(v ?? "").trim()).filter(Boolean))];
    if (ids.length === 0 || ids.length > MAX_BULK) return res.status(400).json({ error: `Choose between 1 and ${MAX_BULK} documents` });
    const folderId = req.body?.folderId ? String(req.body.folderId) : null;
    if (folderId && !(await mine(req.user.id, folderId))) return res.status(404).json({ error: "Not found" });
    for (const id of ids) {
      const row = await queryOne("SELECT * FROM requests WHERE id = ?", [id]);
      if (!row || !(await authoriseAccess(req.user, row))) return res.status(404).json({ error: "Not found" });
    }
    const conn = await getPool().getConnection();
    try {
      await conn.beginTransaction();
      const now = Date.now();
      for (const id of ids) {
        if (folderId) {
          await conn.execute(
            `INSERT INTO folder_items (user_id, request_id, folder_id, added_at) VALUES (?, ?, ?, ?)
             ON DUPLICATE KEY UPDATE folder_id = VALUES(folder_id), added_at = VALUES(added_at)`,
            [req.user.id, id, folderId, now]);
        } else {
          await conn.execute("DELETE FROM folder_items WHERE user_id = ? AND request_id = ?", [req.user.id, id]);
        }
      }
      await conn.commit();
    } catch (e) {
      await conn.rollback();
      throw e;
    } finally {
      conn.release();
    }
    res.json({ moved: ids.length, folderId });
  } catch (e) { next(e); }
});
```

```js
  // Several at once. Same optimism, one revert if the server refuses any of them.
  const moveMany = async (requestIds, folderId) => {
    const ids = [...new Set(requestIds)].filter((id) => (placements[id] || null) !== (folderId || null));
    if (ids.length === 0) return 0;
    const beforeF = folders, beforeP = placements;
    const delta = {};
    for (const id of ids) {
      const from = placements[id] || null;
      if (from) delta[from] = (delta[from] || 0) - 1;
      if (folderId) delta[folderId] = (delta[folderId] || 0) + 1;
    }
    setPlacements((p) => {
      const next = { ...p };
      for (const id of ids) { if (folderId) next[id] = folderId; else delete next[id]; }
      return next;
    });
    setFolders((fs) => fs.map((f) => (delta[f.id] ? { ...f, count: f.count + delta[f.id] } : f)));
    try { await api.fileRequests(ids, folderId); return ids.length; }
    catch (e) { setFolders(beforeF); setPlacements(beforeP); refused(e, "Could not move the documents"); return 0; }
  };
```
