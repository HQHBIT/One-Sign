# HQHB · SignFlow — Quick Reference

**URL:** https://onesign.devhqhb.online  •  **Help:** it@hqhb.in

---

## Sign-in

| Action | Where |
|--------|-------|
| Sign in | URL above → email + password from welcome email |
| Forgot password? | Sign-in screen → "Forgot password?" link → enter email → check inbox |
| Change password | Top nav → **Password** (key icon) → current + new + confirm |
| Sign out | Top nav → **Sign out** |
| Update signature | Top nav → **Signature** (pen icon) |

---

## Requestors — submit a document

1. **Make a new request** (home tile or Quick Action)
2. Pick a type — *Leave / Document / Expense / Invoice / Other*
3. **Upload** PDF or Excel (or use the Leave form if Leave)
4. Pick **Single approver** or **Multi-step workflow**
5. **Drag a box** where the signature goes
6. Pick the **target team** (or build workflow steps)
7. Optional **note** for the approver
8. **Submit**

Track in **Pending requests**. Get a *Reminder* button after 24 h.
Once approved → **Download** or **Print** the signed copy.

---

## Approvers — review and sign

1. **Pending approvals** → click a row → opens the doc
2. **Go to signature** button (top-right of drawer) → jumps to where you'll sign
3. **Preview & approve** → shows your signature on the page
4. **Confirm approval** OR **Go back**
5. Or **Reject** with a reason

Within 1 hour you can **Withdraw** from *Approved requests*.

**Batch approve** same-type requests: filter chip → tick boxes → **Approve selected**.

## Mobile

- Pinch to zoom on PDFs.
- Top nav collapses to icons — same actions.
- iPhone: Safari → Share → **Add to Home Screen** for a standalone app feel.
- Long PDFs lazy-load page by page; **X / Y loaded** indicator at the top.

## What gets emailed

| Event | You receive |
|-------|-------------|
| Account created | Welcome email with credentials |
| Password reset | Email with new password |
| Your doc was approved | *Approved: [name]* |
| Your doc was rejected | *Rejected: [name]* (with reason) |
| A doc needs your signature | *New signature request: [name]* |
| Someone reminded you | *Reminder: "[name]" awaiting approval* |

## Status pills

| Pill | Meaning |
|------|---------|
| 🟡 **PENDING** | Awaiting signature |
| 🟧 **APPROVED · 1H WINDOW** | Signed, can still be withdrawn (1h countdown shown) |
| 🟢 **APPROVED** | Final, signed PDF available |
| 🔴 **REJECTED** | With reason from approver |

## Troubleshooting in 30 seconds

| Problem | Fix |
|---------|-----|
| Can't sign in | Try **Forgot password?** → email arrives → use new password |
| Pop-up blocked on print | Allow pop-ups for this site, try again |
| 63-page PDF "error" on mobile | Hard refresh, give it 5 seconds for the loader. Loader text says **X / Y loaded** |
| Stale data | Each list auto-refreshes; or pull-down / leave tab + come back |
| Lost the password I just generated | Admin → Users → reveal it from the row |
